# Synthetic examples — not trading inputs

All three data files here are fictional walkthrough data from Gamma Quant.
They are not current market observations. The browser selects the synthetic
checkbox for filenames containing template, demo, or synthetic. Do not rename
one and claim it is real.

Prefer demo-gex.json for compatible underlying candles/options at a common cutoff.
The CSV files illustrate column formats. Attach option templates only to their
matching synthetic underlying, never unrelated real observations.
Blank OI is unknown, not zero. No row implies execution certification.
